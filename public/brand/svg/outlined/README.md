# Outlined mark — files (23 September 2026)

The founder prefers the outlined construction (the two stroked circles) over the filled mark (rework/rulings §13; his "yes" of 23 September to using it in the lockup and favicon now). These files are the header lockup and the favicon rebuilt with that mark. Geometry is the master's, untouched: outer r240 at (500,530), inner r200 at (500,455); only the fill became a stroke.

- bidaya-lockup-3-header-outlined.svg — the header lockup, ink, hairline, بداية (stroke 22 in construction units, so the ring reads at 40px).
- bidaya-lockup-3-header-outlined-paper.svg — the same on a band.
- bidaya-mark-outlined.svg / -paper.svg — the mark alone (stroke 14).
- favicon-outlined.svg — paper strokes at 62% on the rounded aqua field (stroke 30); favicon-outlined-small.svg — heavier (46) for 16px.

The site uses the header lockup and the favicon from here. The brand-systems chat may replace them with the identity spec v2's files.
